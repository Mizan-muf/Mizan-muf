## Featured Projects

### Vocalytics-V0.3
AI-driven sales analytics platform that converts voice commands into Plotly-based analytics workflows and natural-language summaries using OpenAI models. Includes CSV ingestion, encoding detection, AST-validated code execution, LightGBM forecasting, and Windows deployment.

**Stack:** Python, Flask, Pandas, Plotly, OpenAI API, LightGBM, SpeechRecognition, gTTS, Pydub, FFmpeg, chardet, cx_Freeze  
**Repo:** [Vocalytics-V0.3](https://github.com/Mizan-muf/Vocalytics-V0.3)

### Intelli-News-v1.1
Modular news intelligence pipeline for crawling, scraping, proxy management, and SQLite-based ingestion across regional news sources. Includes robots-aware crawling, retry logic, browser fallback, and batch ingestion.

**Stack:** Python, curl_cffi, Requests, BeautifulSoup, Readability, SQLite, Playwright, multithreading, JSON  
**Repo:** [Newsletter-Intelli-version-1.1.0](https://github.com/Mizan-muf/Newsletter-Intelli-version-1.1.0)

### ACORD Forms Extraction
Layout-aware ACORD extraction pipeline using visual learning, computer vision, and OCR for text, tables, checkboxes, and document structure. Includes self-learning through visual-model tuning and version switching for safer iteration and rollback.

**Stack:** Python, Computer Vision, Visual Document Models, OCR, PDF parsers, Pydantic, FastAPI/Flask, PostgreSQL

### Distributed Network Monitoring Platform
Two-tier server + agent platform for inventory, health metrics, and DPI alerts across **700+ endpoints** with sub-**200ms** updates, dashboards, and operational alerting.

**Stack:** Python, Flask-Socket.IO, MongoDB, Redis, Elasticsearch, Scapy/psutil, Docker
